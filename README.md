📺 项目介绍
Android TV Cleaner 是一款基于 ADB(Android Debug Bridge) 的安卓电视优化工具。
通过连接电视 ADB 调试接口，可以自动扫描电视中的应用，并生成专属精简方案。
相比传统手动输入 ADB 命令，本工具可以：
自动识别电视应用
获取应用名称、包名、安装路径
自动生成精简列表
自定义保留和删除应用
分级执行系统优化
批量安装常用 APK
目前主要用于：
小米电视
海信电视
TCL电视
创维电视
康佳电视
长虹电视
其他 Android TV / 安卓电视设备
只要设备支持 ADB 调试，并拥有应用管理权限，理论上均可使用。

❓ 常见问题
Q：所有电视都支持吗？
A：
不是。
需要满足：
Android系统
支持ADB
允许应用管理
部分运营商定制系统可能限制较多。
Q：精简后会变砖吗？
A：
正常情况下不会。
本工具默认采用应用卸载/用户层禁用方式，不修改系统分区。
Q：为什么扫描需要较长时间？
A：
深度解析需要读取APK信息。
应用数量越多，耗时越长。
