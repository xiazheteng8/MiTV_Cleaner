# 小米电视一键精简助手 TV_Clean


一款基于 ADB 的小米电视系统精简工具。

下载 https://github.com/xiazheteng8/MiTV_Cleaner/releases/tag/miTV_Cleaner1.0
TV_Clean.zip

解压并运行 TV_Cleaner.bat

通过电脑连接电视后，可以自动完成：

- 安装第三方桌面
- 设置默认桌面
- 删除小米电视广告、推荐、商城等预装应用
- 安装 YouTube 客户端
- 自动重启电视

适合想打造 **纯净 Android TV 桌面体验** 的用户。

## 功能介绍

### ✅ ADB 自动连接

输入电视 IP 地址：

192.168.x.x

工具会自动连接：

ADB TCP 5555


首次连接时，电视会弹出：

是否允许ADB调试？

请使用遥控器点击：

允许

建议勾选：

始终允许此电脑

## 支持桌面

内置以下第三方桌面：

### 1. ATV Launcher

轻量、简洁。

文件：

ATV_Launcher.apk


### 2. 当贝桌面

适合国内电视用户。

文件：

dbzm.apk

# 使用方法


## 1. 准备电脑

Windows 系统。

确保：

- 电脑和电视连接同一个局域网
- 电视开启 ADB 调试


---

## 2. 开启电视 ADB


进入：

设置
 ↓
关于
 ↓
产品型号

连续点击产品型号。


开启开发者模式后：

进入：

设置
 ↓
账号与安全
 ↓
ADB调试

打开。


---

## 3. 查看电视IP


进入：

设置
 ↓
网络

查看：

IP地址


例如：

192.168.1.100


---

## 4. 运行工具


双击：

TV_Clean.bat


输入电视 IP：

请输入电视IP地址:
192.168.1.100


电视弹出 ADB 授权：

使用遥控器：

允许


---

## 5. 选择桌面


根据需要选择：

1 ATV Launcher
2 当贝桌面
3 Emotn UI
4 Projectivy Launcher


工具会自动：

- 安装桌面
- 设置默认 HOME
- 启动测试

安装过程可能需要电视授权

---

## 6. 系统精简


确认桌面正常后：

工具会删除：

- 广告组件
- 推荐服务
- 小米商城
- 游戏中心
- 视频推广
- 部分预装应用


---

## 7. 安装 YouTube


精简完成后：

选择：

1 安装 YouTube

工具会自动安装：

youtube.apk

安装过程可能需要电视授权

# 注意事项 ⚠️


## 1. 请先安装第三方桌面

删除系统桌面前：

必须保证：

- 第三方桌面安装成功
- HOME键可以进入新桌面


否则可能出现：

开机卡MI
无法进入桌面


---

## 2. 不建议恢复出厂设置


精简后：

恢复出厂可能导致：

- 桌面恢复
- 应用重新出现


---

## 3. 不同型号兼容性不同


本工具主要针对：

- 小米电视
- 小米盒子
- Android TV 系统


不同型号可能存在：

- 包名不同
- 系统组件不同


使用前建议确认。


---

# 恢复系统


ADB 卸载并不会删除系统 APK。

部分应用可以恢复：

adb shell cmd package install-existing 包名


例如恢复小米桌面：

adb shell cmd package install-existing com.mitv.tvhome

简单粗暴：设置——更多
