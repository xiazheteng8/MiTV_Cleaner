项目介绍
AndroidTV Cleaner 是一款基于 ADB 调试功能开发的安卓电视优化工具。
通过连接电视，可以自动扫描设备中的应用信息，并根据扫描结果生成自定义配置。
相比传统固定列表方式，新版本采用：
自动扫描
应用解析
自定义配置
分级优化
支持不同品牌、不同系统版本的安卓电视进行个性化管理。
功能特点
1. 自动扫描应用
自动获取：
应用名称
Package Name
APK安装路径
生成完整扫描结果。
2. 自定义优化列表
根据扫描结果生成：
普通优化列表
深度优化列表
桌面优化列表
保护组件列表
用户可以根据自己的需求调整配置。
3. 分级优化
普通优化：
适合日常使用。
深度优化：
适合高级用户。
桌面优化：
用于替换系统默认桌面。
4. 第三方桌面安装
支持：
当贝桌面
ATV Launcher
Emotn UI
Projectivy Launcher
5. 批量安装 APK
将 APK 放入 APPS 文件夹。
工具会自动识别并安装。
适用于：
初始化电视
恢复环境
快速部署应用
使用方法
第一步：开启 ADB 调试
电视设置：
设置 → 关于本机 → 系统版本
连续点击确认键开启开发者模式。
打开：
ADB调试
未知来源应用安装
第二步：获取电视IP
进入：
网络设置 → 网络详情
记录 IPv4 地址。
第三步：运行工具
打开：
TV助手.bat
输入电视IP。
电视授权后即可开始使用。
